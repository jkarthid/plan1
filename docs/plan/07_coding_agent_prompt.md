Build the TaskDesk application described in the plan. Implement full functional behavior and negative paths, not stubs or mocks. Do not change the original docs/plan files to relax requirements.

All new application source, tests, design and validation belong in THIS repository. Use an isolated feature branch and publish code to this same repository. Do not modify the codefactory's own source checkout. Never commit environment files, credentials, SQLite databases, logs with private data, virtual environments, dependency caches, or browser sessions. Use conventional commits via git commit -F with the message file kept outside the checkout. No deployment. Report what passed, failed, and remains.
