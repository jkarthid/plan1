# UI specification

App title: TaskDesk, by Teksbuild. Light background, navy headings, teal actions. Avoid exposing internal agent implementation jargon.

Main workspace: project selector/list with counts, create-project form, selected-project summary, status filter (All/To do/In progress/Done), task list with owner, due date, status, edit and delete controls. New-task form and edit form have persistent visible labels and inline error feedback. Provide confirmation before deletion. Disable submitting controls during requests, preserve user-entered data after failure, and refresh project summaries after task mutations.

At 390px wide the workspace must remain usable without horizontal page overflow. Keyboard-only users can reach and use all controls. Empty state explains how to add the first project/task. No fake dashboard counts or simulated success responses. Refresh page and restart server must retain saved records.
